# Tindog Project

Tindog is a responsive web application inspired by popular dating apps, built to showcase UI/UX design skills and front-end development.  
It features interactive elements, modern layout, and mobile-friendly design.  
Built with **HTML**, **CSS**, and **JavaScript**.

---

## 🌐 Live Demo

Try it here: [https://bahadirbektore.github.io/tindog-project/](https://bahadirbektore.github.io/tindog-project/)

---

## 🚀 Features

- Responsive and mobile-first design  
- Modern layout with interactive UI elements  
- Hover effects and animations  
- Clean and readable code structure

---

## 🛠 Technologies

- HTML5  
- CSS3 (Flexbox & Grid)  
- JavaScript (Vanilla JS)
